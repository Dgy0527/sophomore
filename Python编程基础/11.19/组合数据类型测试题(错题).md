# 1、sorted()
## 升序;不会修改源列表,会返回一个新的排序后列表

# 2、set()
## 创建一个空集合

# 3、执行`li=[1,2,3];del li`之后,li变量已不存在,访问会报错
## `del li`会删除li变量及其引用的列表对象,后续访问li会触发未定义变量

# 4、集合不支持索引访问

# 5、执行`list('python')`后,结果为('p','y','t','h','o','n')
## list()接收可迭代对象(如字符串)时,会将其拆分为单个元素组成列表

# 7、执行`li=['x','y,'z'];li.reverse()`后,结果为['z','y','x']
## reverse()用于逆置列表,将原列表元素从右至左重新排列,直接修改原列表

# 8、add()用于向集合中添加一个元素

# 9、整数不支持in运算

# 10、clear()仅清空列表元素,列表对象仍存在(变为空列表)
## del删除整个列表对象;pop()仅删除单个元素;remove()要传参数

# 11、`t=(1,2,3,4);print(t[1:3])`结果为(2,3)
## 切片[1:3]获取索引1到2的元素(不包括3)

# 12、li=['a','b','c','d','e'] 执行 li[:3] 结果为 ['a','b','c']
## 切片省略m(起始索引)时,默认从0开始;li[:3]即截取索引0~2的元素(a,b,c)

# 13、li=[1,2,3];li.append((4,5));li.extend((4,5)) 结果为 [1,2,3,(4,5),4,5]
## append((4,5))将元组作为整体添加;extend((4,5))将元组元素4,5逐个添加

# 14、li[1,2,3,4,5];li[::-1] 结果为 [5,4,3,2,1]
## 步长step=-1表示逆序截取;li[::-1]等价于将列表反转

# 15、元组的特点 :元素不可修改
## 元组是序列类型,元素有序且可重复,但不可修改
